# 第一阶段回测假设

## 固定范围

- 单只 ETF；
- 日线行情；
- 只做多，不做空；
- 全仓买入、全部卖出；
- 现金和持仓不能为负数；
- 不连接券商，不自动下单。

## 信号与成交

1. 使用交易日 `t` 的收盘数据计算信号。
2. 信号在 `t` 日收盘后才视为已知。
3. 在下一交易日 `t+1` 的开盘价模拟成交。
4. 若没有下一交易日或下一交易日开盘价不可用，该信号不成交。
5. 不允许使用当日收盘信号在当日开盘或收盘成交。

这项规则用于避免未来数据。

## 仓位和数量

- 默认每手 `100` 份，可通过配置修改。
- 买入数量向下取整到完整手数。
- 买入时必须预留手续费和滑点成本。
- 卖出数量不得超过当前持仓。
- 回测结束时不强制平仓，未平仓持仓按最后一个收盘价计入期末资产。

## 手续费

```text
commission = max(abs(notional) × commission_rate, minimum_commission)
```

默认参数：

- 手续费率：`0.0003`
- 最低手续费：`0.0`
- 卖出税率：`0.0`

默认值只是研究假设，不代表任何券商的真实收费。复盘真实交易时优先
使用交易记录中的实际 `fee`。

## 滑点

默认滑点率为 `0.0001`：

```text
买入成交价 = 下一交易日开盘价 × (1 + slippage_rate)
卖出成交价 = 下一交易日开盘价 × (1 - slippage_rate)
```

## 现金、分红和利息

- 闲置现金默认不计利息。
- 第一阶段不单独模拟现金分红、拆分和合并。
- 长期收益研究如使用复权价格，必须在结果中注明。

## 估值与绩效

每个交易日收盘后：

```text
总资产 = 现金 + 持仓数量 × 当日收盘价
```

资金曲线基于收盘后总资产。绩效指标使用统一的
`docs/metrics.md` 定义。

## 订单状态

每个策略信号都会留下订单审计记录：

- `FILLED`：订单已按下一交易日开盘价模拟成交；
- `REJECTED`：因已有持仓、当前空仓或资金不足而未成交；
- `EXPIRED`：信号位于数据最后一天，没有下一交易日可供成交。

成交表只记录 `FILLED` 订单，订单表同时保留未成交信号及原因。

## 买入并持有基准

- 在比较区间第一个交易日的开盘价建仓；
- 使用与策略回测相同的初始资金、整手数量、手续费和滑点；
- 建仓后不再主动交易，期末不强制卖出；
- 每日按照收盘价计算持仓市值和总资产。

## 可重复性

每次回测结果必须记录：

- 数据文件和数据版本；
- 策略参数；
- 初始资金；
- 手续费、最低手续费、税率和滑点；
- 每手数量；
- 运行时间；
- 代码或策略版本。
