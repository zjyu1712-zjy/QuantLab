# 轻量因子研究：价格动量与滚动年化波动率

因子已接入多 ETF 研究集合，支持 20/60/120 期价格动量、20/60 期年化波动率。
分别回答“过去涨跌多少”和“收益率波动多大”，不提供买卖指令，也不代表第二阶段已经全部完成。
现有 Python 调用入口和“因子研究”页面，支持同日单因子排名；暂不提供组合回测或自动保存结果。

## 页面怎么用

1. 在“多 ETF 数据”中准备并保存研究集合，然后进入侧栏“实验 → 因子研究”。
2. 选择已保存集合，再选择价格动量或年化波动率及其周期，点击对应的计算按钮。
   默认仍为 20 期价格动量。只读取已保存快照，不修改行情文件。
3. 在“当日结果”选择日期。默认按 ETF 代码排列，也可以选择“因子排名”，
   再选择从高到低或从低到高。`—` 是不可计算，不是 0%；日期不满足条件时，
   不会偷偷退回前一个有效日期。
4. 在“单只 ETF … 变化”选择代码，查看整个快照区间的曲线。上方日期选择
   只影响当日表，不截断历史曲线。缺失区间断开，全区间无有效值时只显示原因。
5. 展开逐日明细或“公式、来源与研究限制”，核对公式版本、数据版本、复权口径、
   日期轴及指纹。窄窗口下来源表可横向滚动查看长字段。

| 选择 | 热身空值 | 第一个值至少需要 |
|---|---|---|
| 20 期动量 | 前 20 个日期位置 | 21 条完整观测 |
| 60 期动量 | 前 60 个日期位置 | 61 条完整观测 |
| 120 期动量 | 前 120 个日期位置 | 121 条完整观测 |
| 20 期年化波动率 | 前 20 个日期位置 | 21 个收盘价，产生 20 个收益率 |
| 60 期年化波动率 | 前 60 个日期位置 | 61 个收盘价，产生 60 个收益率 |

热身空值是正常现象；历史不足时不会自动读取快照区间以外的行情。
切换集合或因子、快照内容改变、计算失败后都会清除旧结果，需要重新点击计算。
结果只保留在当前会话内；临时公开模式沿用每个会话的独立目录。
本页描述历史价格，不判断是否值得买入，也不代表已经完成因子有效性检验。

### 同日因子对比与排名

- 一次只比较当前研究集合、指定日期、同一个因子及周期的 ETF。不是全市场
  排名，不混用各 ETF 最近的有效日期，也不混合 20/60/120 期或不同因子。
- 动量默认从高到低，波动率默认从低到高，可手动反转。名次只表示所选
  方向的排列，不是投资优劣。低波动不保证安全，历史涨幅不预测未来收益。
- 按未四舍五入数值排名，完全相同的值并列并跳号，例如 `1、1、3`。
  并列项按 ETF 代码排列；仅格式化后的百分比相同，不一定是同一个原始值，
  因而可能名次不同。没有额外的近似相等容差。
- 只有当日有效值参与，真实的 0 正常参与。历史不足、缺失窗口或数值越界
  的 ETF 仍留在表尾，名次为 `—` 并显示原因，不占名次。
- 页面显示“可参与排名数量 / 集合 ETF 总数”。不足两只时提示不能有效横向
  比较；所有可用值相同时仍保留并列名次，但明确提示无法据此区分 ETF。
  切换日期会重新排名；单只 ETF 曲线仍展示完整快照区间。
- 切换集合、因子或重新计算会清除旧排名控件状态，回到代码顺序；再次进入
  排名时采用当前因子的默认方向。返回代码视图也不会改变原计算结果。
- 本步只增加研究展示，不做前 N 只筛选、多因子综合评分、调仓、权重或交易。

代码实现位于 `src/quantlab/ui/factors.py` 的 `ranked_factor_table()`：先复制
指定日期的结果 → 仅对有效的原始数值赋名次 → 按名次和代码排列、空值放最后
→ 格式化百分比。页面负责显示方式、方向和样本数量提示，不重复计算因子，
也不改写研究快照。这是展示层辅助函数，尚非组合构建接口。

`compute()` 返回数值序列；`evaluate()` 同时返回数值与不可用原因。
它们复用同一套公式。研究时建议使用 `run_research_factor()`，而不是绕过
快照校验直接传入任意行情表。默认注册表显式包含 `momentum_20`、
`momentum_60`、`momentum_120`、`volatility_20`、`volatility_60`，不支持任意公式输入。

三个类 `Momentum20Factor`、`Momentum60Factor`、`Momentum120Factor` 只声明
各自周期，共享同一个计算方法。说明书中的周期同时决定计算窗口、公式和页面
文字。原 `Momentum20Factor`、默认 Python 调用和 20 期数值/状态/版本保持不变。

`Volatility20Factor` 和 `Volatility60Factor` 共享波动率算法；没有修改第一阶段
的风险指标函数。两者的样本标准差、简单收益率和 252 期年化口径与第一阶段一致，
区别是这里对每只 ETF 逐日滚动计算，并保留不可计算原因。

## 2. 先用手算理解公式

```text
momentum_N[t] = close[t] / close[t-N] - 1
N = 20、60 或 120
```

`t` 是研究日期轴的位置。当前价格 110、20 个位置前的价格 100，且含
当前在内的 21 条观测都完整，则 `110 / 100 - 1 = 0.10`，即 10%。
常价对应 0，价格从 200 跌到 180 对应 -10%。

这里是 N 个日期轴间隔，不是 N 个自然日。每只 ETF 都保留同一条日期轴，
不能先删除缺失行再计算。窗口中间缺一条也必须留空，不能只检查首尾价格。
缺失完全移出 N+1 条窗口后，才能恢复计算。前 N 条一定保留为热身空值。

### 波动率公式

```text
r[t] = close[t] / close[t-1] - 1
volatility_N[t] = std(r[t-N+1], ..., r[t], ddof=1) × sqrt(252)
N = 20 或 60
```

`std` 是样本标准差，分母为 N−1，衡量收益率围绕其均值的离散程度。
例如 20 个收益率中一个为 10%、其余为 0，则样本标准差为 `0.1 / sqrt(20)`，
年化波动率为 `0.1 × sqrt(252 / 20)`，约 35.50%。不是价格水平的标准差，
不是动量除以周期，也不是把收益率直接乘以 252。

N 个收益率需要 N+1 个完整收盘价。窗口内哪怕只缺一个中间价格，也留空；
当该价格完全移出窗口后恢复。所有收益率相同（包括恒价）时波动率为 0，
这是有效结果，仍显示 0.00% 和曲线；不足 N 个收益率时则显示 `—`。

实现步骤：先检查输入 → 找完整价格窗口 → 算相邻简单收益率 → 检查数值范围
→ 缩放收益率后求样本标准差并还原尺度 → 乘以 √252 → 附上状态。
缩放用于避免平方计算溢出，不裁剪收益率；浮点近似可能带来极小舍入误差。

252 是这两个 1.0 定义内的固定日线年化假设，不自动采用实际年度交易日数，
也不是对日历真实性的认证。日期轴漏日会使相邻价格跨多个交易日；这时年化值
仅供近似研究，不能当作已经校准的日波动估计。尚未提供年化参数输入或频率推断。

## 3. 结果中的四种状态

| `status` | 含义 | `factor_value` / `is_valid` |
|---|---|---|
| `warmup` | 前 N 个位置，历史长度不足 | NaN / False |
| `missing_window` | 已有足够位置，但窗口内存在缺失观测 | NaN / False |
| `numeric_range` | 完整窗口的结果超出可靠数值范围 | NaN / False |
| `valid` | 完整窗口且能可靠计算 | 有限小数 / True |

优先判断热身，再检查窗口缺失，再检查数值范围。极端比值不输出无穷，
也不把舍入成 -1 的价格比值收益率冒充精确 -100%。波动率窗口中任一收益率
不可可靠表示，或最终年化值超出有限范围，都标为 `numeric_range`。
全缺失的 ETF 不会被删除。
零成交量本身不使已存在的价格观测失效，但不代表一定能成交。

这些状态只解释当前输入为什么算不出值，不诊断数据商故障、停牌等真实原因。
所有 ETF 均无可用因子值时仍返回完整表，并给出提示，不把空值当成 0。

## 4. 从已经保存的快照计算

在项目 Python 环境中使用下面的函数。`research_dir` 是已有研究集合目录，
`set_id` 来自已有保存记录；示例没有替你创建集合或指定私人数据路径。

```python
from pathlib import Path
from quantlab.data.research_storage import load_research_set
from quantlab.factors import FactorRunResult, run_research_factor


def calculate_saved_momentum(
    research_dir: Path, set_id: str, factor_name: str = "momentum_20",
) -> FactorRunResult:
    loaded = load_research_set(research_dir, set_id)
    return run_research_factor(loaded.preview, factor_name)
```

逐行理解：

1. `Path` 表示本地目录；其余导入分别提供快照读取、结果类型和计算入口。
2. `load_research_set()` 读取选定快照并核验文件指纹和内容约定。
3. `run_research_factor()` 复制并再次校验预览，在内存里逐只计算，再合并
   为独立结果。不回读来源行情、不补区间外历史、不写回 `aligned.parquet`。
4. 返回对象的 `data` 用于后续分析；`definition`、`sources`、`calendar`
   用于核对公式、数据来源和日期轴。也可以直接传入尚未保存的有效预览。

省略 `factor_name` 保持原来的 20 期行为；传 `"momentum_60"` 或 `"momentum_120"`
选择长周期。页面、图表、明细和热身警告都使用本次结果的因子说明。

同一个 `run_research_factor()` 入口传 `"volatility_20"` 或 `"volatility_60"`
即可计算波动率；上面的加载函数也能原样传入这些名称，函数名仅是示例名称。

展示辅助函数 `factor_history()` 会在返回表的 `attrs` 中附带不可变因子说明。
把该表直接传给 `history_factor_table()` 或 `build_factor_chart()`，会自动使用
正确周期；不会把长周期结果默认标成 20 期。手工构造、丢失该说明的历史表
需要显式传入匹配的 `FactorDefinition`；缺少说明或与附带说明冲突时明确报错。

`result.data` 的列固定为：

```text
date | symbol | factor_value | is_valid | status
```

其日期/代码组合及行顺序和输入一致，包含全部热身及缺失行。行索引标签
不参与数据身份：内部副本会清除可能与列名冲突的索引名称，验证后重置
行标签；调用方索引不变。因子返回错序、缺行、错误类型或矛盾状态时明确
报错，不依靠自动对齐来修补。未知因子或已被修改的预览也会拒绝运行。

冻结结果对象的字段不等于其表格和字典不可修改；它们是与输入分离的副本。
修改结果不会改变原预览，但也不应把被自己改过的结果当成未经修改的计算产物。

## 5. 数据身份与公式身份

- `definition`：名称、公式、版本、字段、周期、方向、缺失规则及可用时点。
  名称区分因子及周期；当前版本均为 `1.0`，规则均为 `strict_window`、`after_close`。
  波动率方向为 `higher_is_more_volatile`，只是“数值越大，历史波动越大”，
  不是“越大越好”或“低波动一定更安全”。公式明确记录 `ddof=1` 与 `sqrt(252)`。
- `input_preview_sha256`：绑定本次研究输入、来源和声明。
- `alignment_content_sha256`：绑定对齐行情内容与日期轴语义。
- `start/end/calendar`：研究区间，以及完整日期轴、模式、来源、覆盖声明、
  日历文件和输入日期指纹；不仅仅保留开始与结束日期。
- `adjustment/sources`：复权标签、每只 ETF 的版本、数据来源、导入时间、
  文件/元数据/完整规范历史三个指纹及口径声明依据。
- `warnings`：原研究限制加上因子适用范围提示。

来源采用既有白名单，排除机器上的 `processed_path`，不附加环境变量、
访问凭证、个人交易或任意原始元数据。完整历史指纹只是身份声明，不是
区间外的价格数据；不能据此跳过热身。指纹也不是数据真实性认证或数字签名。

## 6. 必须保留的研究限制

- 行情日期并集可能漏掉全部 ETF 同时缺失的日期；使用显式日历可能改变
  窗口和结果。保留来源声明，不把用户提供的日历当成已经官方认证。
- 保留已有 `none/qfq/hfq` 标签和依据，不执行复权转换。同一标签不保证
  不同来源算法一致。未复权价格可能受分红、拆并份额影响，动量不是总回报。
- 包含当日收盘价的因子仅在收盘数据可用后计算，不能声称收盘前已知。
  此处不整体滞后一日；未来策略模块应单独规定执行时点和成交假设。
- 不使用未来行，不等于数据在历史当时可得；事后修订和复权信息仍可能
  带来偏差。本结果是固定数据版本上的回顾性价格描述。
- 数值越大只说明过去价格涨幅更高，不证明未来收益更高、策略能盈利或
  市场能按指定价格成交。尚未加入交易成本、组合或因子有效性检验。
- 上一条的涨幅解释仅适用于动量。波动率只描述历史收益率变化，不预测未来
  波动或收益；低波动不保证安全。未复权价格的分红、拆并份额跳变也会影响
  波动率，它不是总回报收益率的波动。
