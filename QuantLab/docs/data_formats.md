# QuantLab 数据导入与统一格式

## 普通用户如何添加行情

“添加资产数据”页面提供三种入口：

1. 自动获取行情：输入 ETF 代码和日期后，通过配置的数据源获取行情；
2. 上传历史行情文件：系统自动识别常见中英文字段和日期格式；
3. 下载 QuantLab 行情模板：适合暂时无法自动识别的文件。

当前支持 QuantLab、东方财富、同花顺、通达信和 Yahoo Finance 的常见
历史行情文件。自动获取支持 AkShare 和已配置凭证的 iFinD QuantAPI，
二者均只用于当前的沪深 ETF 日线。雪球文件、JoinQuant 聚宽、Baostock、
Wind 和 Choice 尚未接入。

用户只需在页面选择资产、上传文件并确认预览。字段识别、自动检查和内部
格式转换由系统完成；技术细节收纳在页面的“高级信息”中。

## 自动获取行情

第一阶段支持沪深 ETF 日线行情，代码可以写成 `159516`、`159516.SZ`、
`sz159516`、`510300.SH` 或 `sh510300`，系统会统一提取六位代码。代码是否
真实存在以行情接口返回结果为准。

默认使用不复权行情；高级设置也可选择前复权或后复权。不同复权方式使用
独立缓存，不会混合。系统会自动完成：

```text
检查代码和日期
→ 查找本地缓存
→ 获取缺少的日期区间
→ 统一字段和数值类型
→ 删除完全重复记录并按日期排序
→ 执行质量检查
→ 分别保存原始返回与标准化结果
```

质量检查包括空数据、必要字段、无效日期、重复日期、非正价格、负成交量，
以及最高价和最低价之间的逻辑关系。明显异常不会被静默修正或保存。

自动获取的数据目录为：

```text
data/raw/market/<provider>/<version_id>/
data/processed/market/<symbol>/<version_id>.parquet
```

元信息记录数据源、周期、复权方式、实际行情区间、获取时间和数据版本。
普通页面只显示“数据已保存”，这些内部细节放在高级信息中。

行情数据源通过 `MarketDataProvider` 统一接口接入，页面只调用
`MarketDataService`。未来增加正式授权的数据源时，在
`src/quantlab/data/providers/` 中实现新 Provider，并在数据源工厂中选择，
收益分析和回测模块无需修改。需要 Token 的数据源必须从环境变量或安全
配置读取。

### 可识别字段

| 统一含义 | 可识别名称 |
|---|---|
| 日期 | `date`、`日期`、`交易日期`、`trade_date` |
| 开盘价 | `open`、`开盘`、`开盘价` |
| 最高价 | `high`、`最高`、`最高价` |
| 最低价 | `low`、`最低`、`最低价` |
| 收盘价 | `close`、`收盘`、`收盘价` |
| 成交量 | `volume`、`vol`、`成交量` |

页面下载模板只包含：

```csv
date,open,high,low,close,volume
```

ETF 代码由页面输入，或者从文件中唯一的代码字段自动识别。

## 高级信息：内部数据规则

## 通用规则

- QuantLab 模板使用 UTF-8 编码；外部文件也支持常见中文编码。
- 日期采用 ISO 格式；证券代码始终按字符串处理。
- 原始文件只读保存，不在原文件上修改。
- 标准化结果保存为 Parquet。
- 数据版本至少记录来源文件名、导入时间、文件哈希和标准化规则版本。
- 私人原始数据和处理结果不纳入版本管理。

## 行情导入与版本目录

第一阶段的一次完整导入按以下顺序执行：

```text
外部历史行情文件
→ 原样归档并计算 SHA-256
→ 读取、校验、类型转换和排序
→ 保存版本化 Parquet
→ 保存导入结果
```

每个文件在第一阶段只能包含一只 ETF。文件采用以下目录结构：

```text
data/raw/market/<version_id>/<原文件名>
data/raw/market/<version_id>/metadata.json
data/raw/market/<version_id>/import_result.json
data/processed/market/<symbol>/<version_id>.parquet
```

`version_id` 由 UTC 导入时间和原文件哈希前缀组成。相同 ETF 的不同导入
不会相互覆盖，因此后续研究结果可以追溯到具体数据版本。

## ETF 日行情内部统一格式

每行表示一只 ETF 在一个交易日的行情。

### 必要字段

| 字段 | 类型 | 规则 |
|---|---|---|
| `date` | 日期 | `YYYY-MM-DD`，同一代码和日期只能出现一次 |
| `symbol` | 字符串 | 不允许为空，不进行数学运算 |
| `open` | 浮点数 | 大于 0 |
| `high` | 浮点数 | 大于 0，且不低于开盘、最低和收盘价 |
| `low` | 浮点数 | 大于 0，且不高于开盘、最高和收盘价 |
| `close` | 浮点数 | 大于 0 |
| `volume` | 整数或浮点数 | 大于等于 0 |

内部标准表头：

```csv
date,symbol,open,high,low,close,volume
```

### 可选字段

| 字段 | 说明 |
|---|---|
| `adjusted_close` | 复权收盘价；存在时可用于长期收益研究 |
| `source` | 数据来源 |
| `currency` | 计价货币 |

回测成交使用未复权的 `open`；收益研究必须明确使用 `close` 还是
`adjusted_close`。当前第一阶段默认使用 `close`。

## 个人交易记录 CSV

每行表示一笔实际成交，而不是委托记录。

### 必要字段

| 字段 | 类型 | 规则 |
|---|---|---|
| `trade_id` | 字符串 | 每笔成交唯一 |
| `trade_datetime` | 日期时间 | `YYYY-MM-DD HH:MM:SS`，默认亚洲/上海时区 |
| `symbol` | 字符串 | ETF 代码 |
| `side` | 枚举 | 只允许 `BUY` 或 `SELL` |
| `quantity` | 正整数 | 成交数量 |
| `price` | 浮点数 | 成交单价，大于 0 |
| `fee` | 浮点数 | 本笔全部费用，大于等于 0 |

标准表头：

```csv
trade_id,trade_datetime,symbol,side,quantity,price,fee
```

### 可选字段

| 字段 | 说明 |
|---|---|
| `note` | 主观交易原因或复盘备注 |
| `strategy_tag` | 交易对应的策略或计划标签 |
| `account` | 多账户区分标识 |

同一 ETF 的成交按 `trade_datetime`、再按 `trade_id` 排序，并使用 FIFO
匹配买入和卖出。卖出数量不得超过当时可用持仓。
