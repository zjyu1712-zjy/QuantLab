# 三方比较与交易复盘

## 自动回答的问题

- 双均线策略是否跑赢买入并持有；
- 个人真实交易是否跑赢双均线策略；
- 三种路径分别产生多少交易成本；
- 哪些 FIFO 已平仓交易贡献了主要盈利或亏损。
- 真实成交相对模型预期成交日是准时、提前还是延迟；
- 哪些真实成交没有匹配模型信号；
- 哪些可执行模型信号没有对应真实成交。

## 信号匹配口径

双均线信号在收盘后产生，模型预期成交日为下一交易日。交易复盘按
买卖方向寻找距离真实成交日最近的模型预期成交日，并使用页面设置的
交易日容差判断是否匹配。

- 相差 0 个交易日：按模型日期成交；
- 负数：提前成交；
- 正数：延迟成交；
- 超出容差：模型外交易；
- 没有真实成交匹配的可执行信号：未执行模型信号。

该分类用于描述时点差异，不直接评价交易对错。

## 成本拆解

额外成本率：

```text
(左侧方案成本 - 右侧方案成本) / 初始资金
```

估算的成本影响等于额外成本率的相反数。观察到的收益差减去成本影响，
得到剩余收益差。

这是便于复盘的近似拆解。手续费会影响可买数量和后续复利，因此不能
把剩余收益差完全解释为择时能力。

## 解释边界

剩余收益差可能同时来自：

- 买卖时点；
- 仓位大小；
- 实际成交价格；
- 未执行模型信号；
- 模型之外的主观交易。

QuantLab 已支持真实交易与模型信号的逐笔时点匹配，也会在 CSV 提供
`note` 时展示交易备注，但仍不会武断地把剩余差异归因于某一个原因。
