# QuantLab 指标定义

## 统一参数

- 日线每年期数：`252`
- 年化无风险利率默认值：`0.0`
- 日收益率：简单收益率
- 波动率：样本标准差，`ddof=1`
- 所有价格必须大于 0，且不能包含空值

默认参数集中定义在 `quantlab.config.settings`，调用方可以显式覆盖。

## 日收益率

```text
r_t = P_t / P_(t-1) - 1
```

第一天没有前一期价格，因此不产生日收益率。

## 累计收益率

```text
R_total = P_end / P_start - 1
```

累计收益率描述完整观察区间的总涨跌幅。

## 年化收益率

```text
R_annual = (P_end / P_start)^(252 / N) - 1
```

`N` 为日收益率期数，即价格观测数量减 1。使用复合增长率，不使用
“平均日收益率乘以 252”。

## 年化波动率

```text
Vol_annual = std(r_daily, ddof=1) × sqrt(252)
```

至少需要两个日收益率。只有一个收益率时，无法计算样本标准差。

## 净值曲线

初始净值设为 1：

```text
NAV_t = product(1 + r_i)
```

买入持有时也可表示为 `P_t / P_start`。

## 回撤曲线

```text
Drawdown_t = NAV_t / running_max(NAV_t) - 1
```

回撤为 0 或负数；创新高时为 0。

## 最大回撤

```text
MaxDrawdown = min(Drawdown_t)
```

例如从 1.20 下跌到 0.90，最大回撤为 `-25%`，而不是正的 `25%`。

## 夏普比率

先把年化无风险利率转换为日利率：

```text
rf_daily = (1 + rf_annual)^(1 / 252) - 1
Sharpe = mean(r_daily - rf_daily) / std(r_daily, ddof=1) × sqrt(252)
```

至少需要两个日收益率。若日收益率波动率为 0，夏普比率未定义，程序应
明确报错，不返回无穷大。

## 交易统计

交易统计基于 FIFO 匹配后的已平仓交易，并在盈亏中计入费用。

已实现盈亏：

```text
卖出净收入 = 卖出价 × 匹配数量 - 分摊卖出手续费
买入成本 = 买入价 × 匹配数量 + 分摊买入手续费
已实现盈亏 = 卖出净收入 - 买入成本
```

未实现盈亏：

```text
未实现盈亏 = 当前价 × 剩余数量
             - (买入价 × 剩余数量 + 剩余买入手续费)
```

未实现盈亏不预扣尚未真实发生的未来卖出手续费。

个人真实交易资金曲线按交易日计算：

```text
买入后现金 = 买入前现金 - 成交价 × 数量 - 手续费
卖出后现金 = 卖出前现金 + 成交价 × 数量 - 手续费
当日期末资产 = 现金 + 持仓数量 × 当日收盘价
净值 = 当日期末资产 / 初始资金
```

同一日先按成交时间处理真实交易，再使用当日收盘价计算期末资产。第一
阶段不支持融资，因此买入不得使现金为负，卖出不得超过已有持仓。

```text
胜率 = 盈利的已平仓交易数 / 全部已平仓交易数
盈亏比 = 平均盈利金额 / abs(平均亏损金额)
```

第一阶段把每条 FIFO 匹配记录视为一笔已平仓交易。盈亏为 0 的交易计入
胜率分母，但不算盈利。没有已平仓交易时胜率未定义；没有盈利交易或
没有亏损交易时盈亏比未定义，程序返回 `None`，不得用任意大数替代。

## 统一分析结果

`analyze_performance(prices)` 是第一阶段统一的绩效分析入口，一次返回：

- 日收益率；
- 净值曲线；
- 回撤曲线；
- 累计收益率；
- 年化收益率；
- 年化波动率；
- 最大回撤；
- 夏普比率。

若任一指标因数据不足或数学上未定义而无法计算，统一入口应明确报错，
不得静默填充为 0。

## 统一个人交易分析结果

`analyze_trades(market_data, trade_source, initial_cash)` 是第一阶段个人
真实交易的统一入口，一次返回：

- 标准化并排序后的交易记录；
- FIFO 已平仓匹配和未平仓批次；
- 已实现、未实现和总盈亏；
- 胜率、平均盈亏和盈亏比；
- 每日现金、持仓、市值、总资产和净值曲线。

`trade_source` 可以是交易 CSV 路径或已经标准化的交易表。没有已平仓
交易时，交易统计结果为 `None`；没有盈利或亏损样本时，盈亏比为
`None`。
