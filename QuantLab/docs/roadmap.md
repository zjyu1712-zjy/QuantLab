# QuantLab 开发路线图

QuantLab 是一个本地运行、以 Python 为主、面向个人投资者的量化研究、
策略回测与真实交易复盘平台。项目不包含实时行情、券商连接、自动下单、
实盘交易或盘中交易系统。

产品信息架构采用“我的投资 → 分析 → 实验 → 改进”，让第一次接触量化
投资的个人用户也能从选择 ETF 开始，逐步理解表现、验证方法并完成复盘。

## 本对话实施范围

- 实施并验收：阶段 0、第一阶段。
- 第二阶段的单因子 Top N 等权多 ETF 组合回测 Python 核心已完成；组合界面、基准和档案仍待实施，详见[组合核心说明](portfolio_backtest.md)。
- 第三阶段和最终交付完善仍为路线图。
- 第一阶段的数据、分析、策略、回测和界面模块不得依赖
  `quantlab.factors`。

## 阶段 0：架构与规则统一

**状态：已完成并通过验收。**

目标：建立不会随着功能增加而混乱的基础。

1. 创建项目目录和 Python 环境。
2. 确定行情 CSV 标准格式。
3. 确定交易记录标准格式。
4. 统一收益和风险指标定义。
5. 确定回测成交、手续费和滑点规则。
6. 建立配置、日志、测试和文档目录。
7. 为第二阶段预留 `factors` 接口，但不实现具体因子。
8. 记录后续阶段。

验收输出：

- 可运行的项目骨架；
- 数据格式说明；
- 指标定义说明；
- 回测假设说明；
- 因子扩展接口。

## 第一阶段：个人量化研究 MVP

**状态：已完成并通过自动测试与五个本地页面的人工验收。**

目标：完成单只 ETF 的“分析—回测—复盘”闭环。

### 1. ETF 行情导入

- 提供自动获取行情的接口占位，不在第一阶段接入真实服务；
- 上传常见来源的历史行情文件；
- 支持 QuantLab、东方财富、同花顺、通达信和 Yahoo Finance 常见格式；
- 统一日期和列名；
- 检查缺失、重复和价格异常；
- 按日期排序；
- 保存标准化数据；
- 保留原始文件和数据版本。

### 2. 基础收益与风险指标

依次实现日收益率、累计收益率、年化收益率、年化波动率、最大回撤、
夏普比率、净值曲线和回撤曲线。

每项指标同时完成：

- 公式解释；
- Python 实现；
- 边界情况处理；
- 单元测试。

### 3. 个人交易记录导入

- 导入并校验买卖记录；
- 处理手续费；
- 使用 FIFO 匹配买卖；
- 计算已实现和未实现盈亏；
- 生成个人资金曲线；
- 计算胜率和盈亏比。

### 4. 双均线策略

- 设置短期和长期均线；
- 识别上穿和下穿；
- 生成买卖信号；
- 避免未来数据；
- 在行情图上标记信号；
- 测试特殊情况。

### 5. 简单回测引擎

- 输入初始资金；
- 按时间顺序处理信号；
- 模拟买卖并管理现金和持仓；
- 扣除手续费与滑点；
- 记录订单和成交；
- 生成资金曲线；
- 输出绩效指标。

第一阶段固定范围：

- 单只 ETF；
- 日线数据；
- 只做多；
- 全仓买入、全部卖出；
- 信号产生后下一交易日成交。

### 6. 三方比较

比较买入持有、双均线回测和个人真实交易，分析择时、成本和主观操作
带来的差异，并识别主要收益和亏损来源。

### 7. Streamlit 界面

计算模块完成后，依次建立：

1. 数据管理；
2. 投资表现分析；
3. 双均线回测；
4. 三方对比；
5. 交易复盘。

计算逻辑不得写入页面代码。

### 8. 第一阶段验收

完整流程：

```text
上传ETF行情
→ 上传个人交易记录
→ 查看收益与风险
→ 设置双均线参数
→ 运行回测
→ 查看资金曲线和买卖点
→ 比较真实交易、策略和买入持有
→ 完成交易复盘
```

## 第二阶段：多 ETF 与轻量因子研究

2026-09-30：组合核心已串起研究快照、五个内置因子、固定间隔调仓、
费用/滑点、现金/整手持仓与完整区间绩效，并完成 53 项端到端验收。
这是 Python 核心交付，不是第二阶段整体完成；范围与验收记录见
[组合回测说明](portfolio_backtest.md)。组合界面、基准比较、组合档案/下载
以及稳健性研究仍为后续小步。

本阶段分步实施；组合核心完成并不代表整个阶段完成。

1. 已完成：多 ETF 固定版本管理、交易日期对齐、缺失报告、研究集合保存与重读。
   见[操作与规则](multi_etf_data.md)。本次未扩展行情适配器，也不提供权威交易状态。
2. 正式启用因子模块，研究动量、波动率、均线偏离、趋势、成交量变化
   和历史回撤等轻量 ETF 因子。
3. 记录因子公式、输入、周期、方向、缺失值规则和版本。
4. 实现横截面标准化、排名、前 N 只选择和权重设置。
5. 部分完成：单因子 Top N 等权、多 ETF 固定间隔调仓、只做多不融资、
   整手份额、佣金/滑点/卖出税和组合绩效 Python 核心；自定义仓位限制、
   组合界面、基准比较和组合档案/下载待实现。
6. 进行参数热力图、分年份、分市场环境和收益集中度检查。

验收流程：

```text
导入多只ETF
→ 计算因子
→ 对ETF进行排名
→ 选择前N只
→ 构建组合
→ 回测调仓
→ 查看组合收益和风险
```

## 第三阶段：正式因子研究与实验管理

本阶段当前只记录路线图，不实施。

1. 因子分组回测、IC、Rank IC、换手率、收益曲线和衰减分析。
2. 因子相关性、冗余、极值、标准化、中性化和市场环境分析。
3. 等权、手动权重、IC 加权和因子打分等多因子模型。
4. 样本内外、滚动窗口、Walk-forward 和成本压力测试。
5. 自动检查未来数据、成本、基准、样本外、参数稳定性和收益集中度。
6. 保存研究假设、数据版本、代码版本、参数、假设、结果和结论。
7. 对比真实交易与模型信号，识别规则偏离和行为错误。

验收流程：

```text
提出研究假设
→ 创建因子或策略
→ 历史回测
→ 稳健性与样本外检验
→ 构建多因子组合
→ 保存研究实验
→ 与真实交易比较
→ 形成复盘结论
```

## 最终交付完善

三个核心阶段完成后，再处理一键启动、备份恢复、结果导出、错误提示、
使用说明、示例数据、跨系统检查、性能优化和全流程测试。

最终形成三条主线：

```text
投资分析：真实交易 → 绩效分析 → 行为复盘
策略研究：策略规则 → 回测 → 稳健性验证
因子研究：因子计算 → 有效性检验 → 多因子组合
```
