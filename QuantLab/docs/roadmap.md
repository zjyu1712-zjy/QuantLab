# QuantLab 开发路线图

QuantLab 是一个本地运行、以 Python 为主、面向个人投资者的量化研究、
策略回测与真实交易复盘平台。项目不包含实时行情、券商连接、自动下单、
实盘交易或盘中交易系统。

产品信息架构采用“我的投资 → 分析 → 实验 → 改进”，让第一次接触量化
投资的个人用户也能从选择 ETF 开始，逐步理解表现、验证方法并完成复盘。

  20/60/120 期动量、20/60 期波动率、20 期均线偏离、价格最大回撤、成交量变化及带方向趋势效率，

  已增加固定 20 期动量＋20 期波动率的共同样本、50/50 综合评分观察，不参与组合调仓。
  单因子 Top N 等权多 ETF 组合回测核心、组合界面及同热身期全池等权买入持有基准已接入；
  已接入组合档案保存/历史界面、单次 ZIP 下载，以及从资金曲线派生的分年份表现和收益集中度检查。

3. 确定交易记录标准格式。

5. 确定回测成交、手续费和滑点规则。
6. 建立配置、日志、测试和文档目录。

- 指标定义说明；

## 第一阶段：个人量化研究 MVP

**状态：已完成并通过自动测试与五个本地页面的人工验收。**

2026-09-22 在现有版本上补齐回测运行记录、持久保存和导出，并重新
执行自动化验收。历史人工验收与本次自动化验证的范围详见
[阶段 0/1 收尾验收](stage1_acceptance.md)。

目标：完成单只 ETF 的“分析—回测—复盘”闭环。

### 1. ETF 行情导入

- 支持 CSV 导入，另已接入 AkShare 和可选 iFinD 历史行情服务；
- 上传常见来源的历史行情文件；
- 支持 QuantLab、东方财富、同花顺、通达信和 Yahoo Finance 常见格式；
- 统一日期和列名；
- 检查缺失、重复和价格异常；
- 按日期排序；
- 保存标准化数据；
- 保留原始文件和数据版本。

### 2. 基础收益与风险指标

依次实现日收益率、累计收益率、年化收益率、年化波动率、最大回撤、
夏普比率、净值曲线和回撤曲线。

每项指标同时完成：

- 公式解释；
- Python 实现；
- 边界情况处理；
- 单元测试。

### 3. 个人交易记录导入

- 导入并校验买卖记录；
- 处理手续费；
- 使用 FIFO 匹配买卖；
- 计算已实现和未实现盈亏；
- 生成个人资金曲线；
- 计算胜率和盈亏比。

### 4. 双均线策略

- 设置短期和长期均线；
- 识别上穿和下穿；
- 生成买卖信号；
- 避免未来数据；
- 在行情图上标记信号；
- 测试特殊情况。

### 5. 简单回测引擎

- 输入初始资金；
- 按时间顺序处理信号；
- 模拟买卖并管理现金和持仓；
- 扣除手续费与滑点；
- 记录订单和成交；
- 生成资金曲线；
- 输出绩效指标。

每次回测携带输入数据指纹、数据来源/版本、参数、运行时间和源码指纹。
页面运行后自动保存 JSON；Python API 提供显式保存函数。

第一阶段固定范围：

- 单只 ETF；
- 日线数据；
- 只做多；
- 全仓买入、全部卖出；
- 信号产生后下一交易日成交。

### 6. 三方比较

比较买入持有、双均线回测和个人真实交易，分析择时、成本和主观操作
带来的差异，并识别主要收益和亏损来源。

### 7. Streamlit 界面

计算模块完成后，依次建立：

1. 数据管理；
2. 投资表现分析；
3. 双均线回测；
4. 三方对比；
5. 交易复盘。

计算逻辑不得写入页面代码。

### 8. 第一阶段验收

完整流程：

```text
上传ETF行情
→ 上传个人交易记录
→ 查看收益与风险
→ 设置双均线参数
→ 运行回测
→ 查看资金曲线和买卖点
→ 比较真实交易、策略和买入持有
→ 完成交易复盘
```

2026-10-02 增加固定 N/调仓间隔的小型参数敏感性对比、热力图和收益集中度检查，

   切换仅重绘、不重新回测。已增加当前/历史各自完整曲线的收益集中度：

## 第三阶段：正式因子研究与实验管理

本阶段当前只记录路线图，不实施。

1. 因子分组回测、IC、Rank IC、换手率、收益曲线和衰减分析。
2. 因子相关性、冗余、极值、标准化、中性化和市场环境分析。
3. 等权、手动权重、IC 加权和因子打分等多因子模型。
4. 样本内外、滚动窗口、Walk-forward 和成本压力测试。
5. 自动检查未来数据、成本、基准、样本外、参数稳定性和收益集中度。
6. 保存研究假设、数据版本、代码版本、参数、假设、结果和结论。
7. 对比真实交易与模型信号，识别规则偏离和行为错误。

验收流程：

```text
提出研究假设
→ 创建因子或策略
→ 历史回测
→ 稳健性与样本外检验
→ 构建多因子组合
→ 保存研究实验
→ 与真实交易比较
→ 形成复盘结论
```
